# In Situ Audiolab

**Sitio web desplegado:** [Ver página en Netlify](https://insituaudiolab.netlify.app)

## Descripción del proyecto


In Situ Audiolar es un sitio web desarrollado como proyecto final del módulo de Desarrollo Web. Su objetivo es presentar la identidad, los servicios y la propuesta de valor de Audiolar mediante una interfaz visual intuitiva, moderna y adaptable a diferentes dispositivos. El proyecto integra HTML, CSS y JavaScript, incluyendo animaciones nativas y la librería AOS para mejorar la experiencia de navegación.]
